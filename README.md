# Fila Agentes Suporte

![Versão](https://img.shields.io/badge/vers%C3%A3o-v1.1.4-blue)

Sistema interno para controle operacional da fila de agentes de suporte via WhatsApp, com integração ao Chatwoot.

O projeto tem como objetivo organizar a distribuição de atendimentos entre agentes, controlar status operacionais, gerenciar pausas e manter a fila sincronizada em tempo real para operadores, supervisores e telas públicas.

## Resumo do projeto

O **Fila Agentes Suporte** é um sistema web voltado para equipes de atendimento que precisam controlar, visualizar e organizar a fila de agentes disponíveis para receber conversas no WhatsApp.

A aplicação centraliza informações operacionais importantes, como:

- posição dos agentes na fila;
- status de disponibilidade;
- quantidade de atendimentos ativos;
- controle de pausas;
- temporizadores operacionais;
- apoio à operação integrada ao Chatwoot.

O foco principal do projeto é oferecer uma solução simples, estável e rastreável para o dia a dia da operação de suporte.

## Principais objetivos

- Controlar a fila de agentes de forma clara e previsível.
- Evitar distribuição manual desorganizada de atendimentos.
- Melhorar a visibilidade operacional para supervisores.
- Sincronizar alterações em tempo real.
- Facilitar manutenção e evolução futura do sistema.

## Funcionalidades principais

- Visualização da fila de agentes.
- Login de colaboradores e administradores.
- Controle de agentes disponíveis, em atendimento ou em pausa.
- Temporizadores de fila e pausa.
- Integração com Chatwoot.
